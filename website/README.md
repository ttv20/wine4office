# Wine4Office website concepts

This static page contains ten independent Wine4Office website directions on one
scrollable comparison page.

Run it locally:

```sh
python3 -m http.server 4173 --bind 0.0.0.0 --directory website
```

Then open `http://localhost:4173`.

The two image assets are the supplied Word-on-Linux screenshot and the existing
Wine4Office Manager icon from `tools/wine4office-manager/icons/`.
